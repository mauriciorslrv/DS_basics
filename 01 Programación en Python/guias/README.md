# 📘 Guías · Programación en Python

Estas guías acompañan al recorrido actualizado del **Módulo 01**. Su función es ayudarte a ubicar rápidamente qué estás aprendiendo, qué deberías poder hacer al terminar y cómo se conecta con problemas reales.

Cada guía separa cuatro cosas:

- **qué trabaja la notebook**;
- **la idea central** que conviene conservar;
- **conexiones aplicadas** fuera del ejemplo;
- **un mini reto** para practicar sin copiar una receta.
