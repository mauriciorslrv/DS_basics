# 06 · Visualizar para entender

> **En una frase:** elegir una gráfica según la pregunta y convertir patrones visuales en observaciones interpretables.

📓 [Abrir notebook](../notebooks/06_Visualizar_para_entender.ipynb)

## 🧭 Qué cubre la notebook

- decidir primero **qué quieres entender**;
- gráfica de línea para evolución temporal;
- barras para comparar categorías;
- histogramas para observar distribuciones;
- dispersión para explorar relaciones entre variables;
- boxplots para comparar distribuciones y detectar posibles atípicos;
- uso combinado de Pandas y Matplotlib;
- títulos, ejes, etiquetas y leyendas;
- buenas prácticas mínimas de legibilidad;
- diferencia entre observar una relación y demostrar causalidad;
- interpretación escrita después de una visualización.

## 🧠 Idea central

```text
pregunta → gráfica → patrón → interpretación → nueva pregunta
```

Una visualización útil no empieza eligiendo colores o estilos. Empieza con una pregunta concreta.

## 🌍 Conexiones aplicadas

- evolución de una métrica en el tiempo;
- comparación de regiones, productos o grupos;
- análisis de dispersión y variabilidad;
- detección visual de observaciones atípicas;
- exploración de relaciones entre dos variables;
- comunicación de un hallazgo a una persona no técnica.

## ✅ Al terminar deberías poder

- elegir entre línea, barras, histograma, dispersión y boxplot según la pregunta;
- construir una gráfica básica con título y ejes comprensibles;
- evitar elementos visuales que no aportan información;
- escribir una observación basada en lo que realmente muestra la gráfica;
- reconocer que correlación visual no implica causalidad;
- generar una nueva pregunta a partir de un patrón observado.

Crea un DataFrame pequeño con una variable temporal, una métrica y una categoría. Produce dos visualizaciones distintas y escribe debajo qué pregunta responde cada una y cuál es el patrón principal que observas.
