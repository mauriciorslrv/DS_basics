# 🐍 Módulo 01 · Programación en Python

> **Propósito:** construir la base de programación necesaria para manipular datos, automatizar tareas y preparar análisis reproducibles sin convertir el módulo en un catálogo de sintaxis.

Este bloque está pensado para avanzar desde **cero o muy poca experiencia** hasta una primera forma de trabajo con datos. La idea central es aprender haciendo:

```text
pregunta → intuición → ejemplo → código → prueba → interpretación → mini reto
```

No necesitas memorizar Python. Necesitas aprender a leerlo, experimentar con él y reconocer qué herramienta usar para cada problema.

## 🧭 Cómo estudiar el bloque

1. Lee el objetivo y trata de anticipar para qué sirve el concepto.
2. Ejecuta las celdas en orden.
3. Cambia **una cosa a la vez** y observa qué ocurre.
4. Lee los errores antes de corregir al azar.
5. Haz el mini reto sin copiar exactamente el ejemplo anterior.
6. Usa las referencias como consulta, no como material para memorizar.

## 🌍 La conexión práctica

Una ruta típica de trabajo con datos empieza justo aquí:

```text
archivo / API / tabla
        ↓
Python
        ↓
lógica + transformación
        ↓
NumPy / Pandas
        ↓
visualización
        ↓
interpretación
        ↓
pregunta mejor informada
```

Al terminar el módulo deberías sentirte cómodo leyendo código introductorio, modificándolo, construyendo pequeños flujos propios y entendiendo por qué cada pieza existe.

## ✅ Resultado esperado

Al cerrar el bloque podrás:

- representar información con estructuras básicas de Python;
- tomar decisiones y repetir procesos;
- separar lógica en funciones reutilizables;
- leer y escribir archivos sencillos;
- trabajar con arreglos numéricos;
- inspeccionar y transformar tablas;
- elegir una visualización según la pregunta;
- interpretar resultados antes de saltar a modelos más complejos.

➡️ Después continúa con [02 · Análisis Estadístico de Datos](../02%20Análisis%20Estadístico%20de%20Datos/README.md), donde la pregunta cambia de **“¿cómo manipulo información?”** a **“¿cómo describo variabilidad, incertidumbre y evidencia?”**.
