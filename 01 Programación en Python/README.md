# 🐍 Módulo 01 · Programación en Python

> **Propósito:** construir la base de programación necesaria para manipular datos, automatizar tareas y preparar análisis reproducibles.

Este módulo avanza desde la sintaxis elemental de Python hasta el uso de NumPy, Pandas y Matplotlib. No busca cubrir todo el lenguaje: busca darte las piezas que aparecen una y otra vez cuando trabajas con datos.

## 🗺️ Ruta sugerida

| Paso | Notebook | Qué construyes |
|---|---|---|
| 1 | `Introduccion_a_la_programacion_con_Python.ipynb` | Variables, tipos, operadores, listas y diccionarios |
| 2 | `Las_bases_para_usar_Python.ipynb` | Sets, tuplas, control de flujo, ciclos y funciones |
| 3 | `Modulos_y_Programacion_Orientada_a_Objetos.ipynb` | Reutilización, objetos y trabajo con archivos |
| 4 | `Numpy.ipynb` | Cálculo eficiente con arreglos |
| 5 | `Pandas.ipynb` | Datos tabulares con Series y DataFrames |
| 6 | `Plots.ipynb` | Visualización y exploración de tendencias |

## 🌍 La conexión práctica

Una ruta típica de datos empieza justo aquí:

```text
archivo / API / tabla
        ↓
Python
        ↓
limpieza + lógica
        ↓
NumPy / Pandas
        ↓
visualización
        ↓
pregunta mejor informada
```

Cuando termines el módulo deberías sentirte cómodo leyendo código, transformándolo y construyendo pequeños flujos propios, no sólo ejecutando celdas ajenas.
