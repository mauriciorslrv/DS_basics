# 03 Aprendizaje Máquina

Este directorio contiene notebooks relacionados con el aprendizaje de máquina, específicamente la introducción al Perceptrón.

## Notebooks

- **Introduccion_Perceptron.ipynb**: Introducción básica al Perceptrón, incluyendo conceptos fundamentales y ejemplos simples.
- **Introduccion_Perceptron_P2.ipynb**: Parte 2 de la introducción al Perceptrón, con implementaciones avanzadas, análisis de datos y evaluaciones de modelos.
