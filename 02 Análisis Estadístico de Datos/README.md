# 📊 Módulo 02 · Análisis Estadístico de Datos

> **Propósito:** pasar de “tengo datos” a “puedo describir incertidumbre, contrastar ideas y apoyar una decisión con evidencia”.

El módulo combina fundamentos estadísticos con notebooks aplicadas. Incluye datasets de RR. HH., Iris y películas, además de ejercicios de simulación y obtención de información desde web/APIs.

## 🗺️ Ruta sugerida

| Paso | Notebook | Pregunta que ayuda a responder |
|---|---|---|
| 1 | `1_Fundamentos_Analisis_Estadistico.ipynb` | ¿Qué tipo de datos tengo y cómo los describo? |
| 2 | `2_Medidas_Principales.ipynb` | ¿Qué es típico, qué varía y cómo se relacionan variables? |
| 3 | `3_Distribuciones_Probabilidad.ipynb` | ¿Cómo describo resultados posibles e incertidumbre? |
| 4 | `4_Pruebas_Hipotesis.ipynb` | ¿La evidencia respalda una afirmación? |
| 5 | `5_MonteCarlo.ipynb` | ¿Qué pasa si simulo miles de escenarios posibles? |
| 6 | `6_WebScrapping.ipynb` | ¿Cómo obtengo y proceso información desde la web o una API? |

## 🧠 Regla del módulo

Una estadística no es una respuesta por sí sola. Siempre pregunta:

1. ¿qué representa el dato?;
2. ¿cómo se obtuvo?;
3. ¿qué incertidumbre existe?;
4. ¿qué decisión podría cambiar con este análisis?;
5. ¿qué limitaciones quedan?
