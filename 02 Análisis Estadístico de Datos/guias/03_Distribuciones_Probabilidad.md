# 03 · Distribuciones de probabilidad

> **En una frase:** modelar incertidumbre significa describir qué puede pasar y qué tan plausible es cada resultado.

📓 [Abrir notebook](../notebooks/3_Distribuciones_Probabilidad.ipynb)

## Qué cubre

- variable aleatoria y distribución;
- casos discretos y continuos;
- Poisson para conteos;
- Binomial para éxitos en un número fijo de intentos;
- Normal para variables continuas bajo supuestos adecuados;
- PMF, PDF y CDF;
- Uniforme y muestreo;
- diferencia entre un modelo teórico y los datos observados.

## Idea central

```text
valor observado ≠ único futuro posible

modelo probabilístico
      ↓
rango de resultados + plausibilidad
```

Una distribución es un modelo. Que una curva “se vea bien” no demuestra que el proceso real siga exactamente esa distribución.
