# Libros de práctica · Excel

Carpeta para ejercicios descargables de Excel y análisis de datos del módulo 00.

## Excel narrativo

El archivo `DS_basics_Excel_Narrativo_v2.xlsx` contiene 12 hojas con la historia de una comercializadora ficticia, tablas de ventas, cálculos, análisis de clientes y productos, escenarios, conclusiones y material de apoyo de SQL y PostgreSQL.

Empieza por **Caso · historia** y **00 Cómo usarlo** para seguir la práctica. Los datos comerciales son simulados y no representan resultados históricos.
